# Запис до лікаря

Навчальний HTML/JavaScript проєкт. Варіант 7.

Відкрийте `index.html` у браузері, виберіть спеціаліста, дату й час та натисніть «Підтвердити запис». Це локальна демонстрація: дані нікуди не надсилаються, реального бронювання немає.

Код не потребує бібліотек, сервера або бази даних.

У гілці `feature/update-doctor-appointment-7` додано скасування поточного запису та можливість повторного вибору. Гілку об’єднано з `main` окремим merge-комітом.
